## Project Description
This project is a menu-driven Scientific Calculator developed using the C programming language. It performs basic arithmetic operations as well as various scientific and mathematical calculations.

## Features
- Addition, Subtraction, Multiplication and Division
- Modulus Operation
- Trigonometric Functions (Sine, Cosine and Tangent)
- Square, Cube and Power Calculations
- Square Root and Cube Root
- Natural Logarithm and Common Logarithm
- Factorial Calculation
- Percentage Calculation
- Reciprocal Calculation
- Mathematical Constants (Pi and Euler's Number)
- Input Validation and Error Handling

## Technologies Used
- Programming Language: C
- Compiler: GCC
- Libraries: stdio.h, math.h, stdlib.h, string.h, errno.h and limits.h

## How to Run

1. Download the source code.
2. Open the file using a C compiler.
3. Compile and execute the program.
